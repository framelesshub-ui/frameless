# 📁 Quick Upload Drop Folder

You can drop new media updates and assets here directly via GitHub!

### Dedicated Folders for Public Serving:
- **Client Logos:** [`/public/media/clients/`](../public/media/clients/)
- **Portfolio Videos (.mp4):** [`/public/media/videos/`](../public/media/videos/)
- **Project Case Study Photos:** [`/public/media/work/`](../public/media/work/)
- **General Media:** [`/public/media/uploads/`](../public/media/uploads/)

### How to Upload on GitHub Web:
1. Navigate to any of the folders above (or drop files directly here).
2. Click **"Add file"** ➔ **"Upload files"** at the top right of GitHub.
3. Drag & drop your files and click **"Commit changes"**.
4. Vercel will automatically build and deploy them live within 30 seconds!
