# 📦 General Media Uploads

Upload any general media assets (banners, videos, client photos, PDFs) here.

### How to Upload on GitHub:
1. Click **"Add file"** > **"Upload files"** in the top right.
2. Drag and drop any files.
3. Commit changes.

### Automatic URL Path:
Any file uploaded here is immediately live at:
`https://www.framelesshub.com/media/uploads/<your-file-name>`
