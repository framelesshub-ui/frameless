# 📸 Project Gallery & Work Assets

Upload project stills, photo shoots, editorial mockups, and case study images here (`.jpg`, `.png`, `.webp`).

### How to Upload on GitHub:
1. Click **"Add file"** > **"Upload files"** in the top right.
2. Drag and drop your project visuals.
3. Commit changes.

### Recommended File Naming:
- `birlas-parvai-hero.jpg`
- `ora-kitchen-packaging-1.jpg`
- `aura-home-interior-1.jpg`

### Automatic URL Path:
Any image uploaded here will automatically be available at:
`https://www.framelesshub.com/media/work/<your-file-name>.jpg`
